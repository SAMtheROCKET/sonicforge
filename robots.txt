# One wildcard group is deliberate rather than minimal. Under the robots.txt
# specification a crawler obeys the most specific group that names it and
# falls back to "*" when none does, so this permits every crawler that
# exists now and every one that does not exist yet. Enumerating individual
# crawlers to grant them access they already have would only create a list
# that goes stale.
